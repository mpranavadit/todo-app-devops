What this app is

A task manager built with Flask and SQLite. Tasks are stored in a database, so they survive restarts and redeploys.

Tech stack

  • Flask (Python) for routes and templates
  • SQLite for storage, with add, view, edit and delete
  • Docker to package the app
  • GitHub and Jenkins for the CI/CD pipeline
  • AWS EC2 to host Jenkins and the running app

How a release reaches this page

A push to GitHub triggers Jenkins. Jenkins builds the image, runs the tests, pushes it to Docker Hub, then deploys it to the app server over SSH. Running version: {{ version }}.
